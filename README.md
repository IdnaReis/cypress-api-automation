# 🚀 Cypress API Automation

> Projeto de automação de testes de API com Cypress | Trilha DIO

## 📌 Sobre o Projeto
Repositório desenvolvido durante a **Trilha de Cypress da DIO**, com foco em **testes automatizados de API**.
Objetivo: validar respostas, códigos de status, estrutura JSON e comportamento de endpoints de forma prática e eficiente.

## 🛠️ Tecnologias Utilizadas
- **Cypress** 🟢 — Framework moderno para testes de API e Web
- **JavaScript / Node.js** — Ambiente de execução
- **npm** — Gerenciador de pacotes e dependências

## 📂 Estrutura do Projeto

cypress-api-automation/
├── cypress/               # Arquivos de teste e comandos customizados
├── .gitignore             # Arquivos/pastas ignoradas pelo Git
├── README.md              # Documentação principal
└── package.json           # Configurações e dependências do projetoplaintext

## ✅ Foco dos Testes
- ✅ Validação de **códigos de status HTTP** (200, 201, 400, 404 etc.)
- ✅ Verificação de **estrutura e contrato JSON**
- ✅ Suporte aos métodos: **GET, POST, PUT, DELETE**
- ✅ Cenários de sucesso, erro e autenticação
